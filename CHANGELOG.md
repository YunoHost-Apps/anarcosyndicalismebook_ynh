# Changelog

## [1.3.1~ynh22] - 2026-11-12
- Moved the Composer installation to the `[resources.composer]` manifest resource (version 2.8.3), as required by packaging format 2.1: removed the deprecated `ynh_composer_install` helper and the `composer_version` variable from `scripts/_common.sh`.
- Dependencies are now installed with `ynh_composer_exec` (run as the app user, with `COMPOSER_HOME` isolated in the install directory) in `scripts/install` and `scripts/upgrade`, which removes the `package_check` linter warning.
- Removed `conf/php-fpm.conf`, which helpers 2.1 silently ignore: the PHP-FPM pool is now fully auto-generated by `ynh_config_add_phpfpm`, with app-specific settings in `conf/extra_php-fpm.conf` (`max_execution_time`, error display/logging, `open_basedir`).
- Upload and memory limits are now app settings with defaults set in `scripts/install` and `scripts/upgrade` (`php_upload_max_filesize = 500M`, matching the NGINX `client_max_body_size`, and `php_memory_limit = 256M`), and admins can override them.

## [1.3.1~ynh21] - 2026-11-12
- Optional install parameters (`contact_email`, `smtp_user`, `smtp_password`, `cap_site_key`, `cap_secret_key`) are now explicitly declared with `optional = true` in `manifest.toml`, fixing the Moulinette validation errors.
- Added the default argument set `[default.args]` in `tests.toml` for the YunoHost CI automated tests.
- NGINX sub-path redirect: added the `#sub_path_only rewrite ^__PATH__$ __PATH__/ permanent;` directive in `conf/nginx.conf` to avoid 404 errors when the app is accessed without a trailing slash.
- Replaced NGINX `add_header` directives with `more_set_headers` so that security headers are applied consistently and are not hidden by nested blocks.
- Full pass of the YunoHost automated test suite (`package_check`): 7/7 tests passed, overall quality level 6 reached.

## [1.0.0~ynh2] - 2025-12-17

This release brings major fixes for stability, deployment and email configuration.

### Technical changes and fixes
*   **Installation via Git**: the package now uses `git clone` instead of downloading an archive. This gives the app access to its Git history (versioning) and makes future updates via `git pull` easier.
*   **Database fix**: added an automatic migration that adds the missing `parent_id` column to the `menu` table, fixing access to the menu management page.
*   **Improved email handling**:
    *   The sender address (`SMTP_FROM`) now defaults to the authenticated SMTP user (instead of the admin email), which fixes mail rejections by providers such as Gmail/Outlook (SPF/DKIM).
    *   Added an install option to set a specific **contact email address** (recipient), independent of the administrator.
*   **App fixes**:
    *   Fixed the `require_once` path for `database.php` on the `mon-compte.php` page.
    *   Session variables (first name/last name) are updated immediately after a profile change.
    *   Composer dependencies (PHPMailer) are installed correctly during installation and upgrade.

### Upgrade
To upgrade from a previous version:
```bash
sudo yunohost app upgrade anarcosyndicalismebook -u https://codeberg.org/Anarcosyndicalismebook/anarcosyndicalismebook_ynh
```
*Note: this upgrade fully preserves your data, configuration and database.*
