# AnarcosyndicalismeBOOK

AnarcosyndicalismeBOOK is a specialized digital library CMS designed for sharing activist and alternative documents.

### Core Features:

- **Online Reading** of PDF and EPUB with full-screen mode.
- **File Upload and Management** (TXT, PDF, EPUB).
- **Bulk Import** via drag & drop.
- **Import from Calibre** or Wikisource (metadata.db or OPDS server).
- **Search** by title, author, content.
- **Organization** by thematic categories.
- **Favorites** and personal reading list.
- **RSS Feed** and dynamic XML sitemap.
- **Installable PWA** with offline mode.
- **Comprehensive Accessibility Widget** (dyslexia, contrast, size).
- **Social Sharing** (Mastodon, Bluesky, Telegram, etc.).
- **Universal Ghost CMS Migration**: Automatic and intelligent import from any Ghost site.
- **RSS/Atom Feed Importer**: Ability to migrate content from WordPress or any syndicated feed with automatic detection.
- **Robust Migration System**: Item-by-item error handling to ensure migration never stops due to corrupted text.
- **Full UTF-8 Cleaning**: Automatic text conversion for perfect compatibility with the SQL database.
- **"Anarchist Red" Harmonization**: Complete visual redesign of administration and newsletter using project colors (#b22222).
- **Associated PDF Reader**: Automatic download and linking of remote PDFs during migrations for immediate display in the reader.
- **Logs and Diagnostics**: New error logging system for precise migration tracking.
